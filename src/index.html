Tips if something seems off
  • Buffering? Lower the quality in the player’s settings. 720p is a good place to start.
  • Subtitles: turn them on from the subtitles menu while a video plays. Some titles have more than one language.
  • Casting: the phone apps can cast to a TV. Tap the cast icon while a video is playing. If your TV has its own Jellyfin app, that’s usually smoother.

How it’s built

The whole server is written down as code in a public repo, so it can be rebuilt from scratch with one command. When it boots, a gate holds the apps back until the media drive checks out; if it doesn’t, the machine power-cycles once and then alerts a phone instead of looping forever. Admin tools stay on a private network, and only streaming is public, through a Cloudflare tunnel. Backups are pulled every night and checked for integrity.
